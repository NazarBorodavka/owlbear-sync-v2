Tracker Connection

Map Auto-Zoom

Sets the zoom so one grid square is one token base (40mm) on the table. Use from play-area size: it needs nothing but the calibration you already have.

The option below measures the projected grid through the camera instead. It does not work with the near-IR bandpass filter fitted -- the filter's whole job is to make projector light invisible to the camera, so there is no grid left for it to find. Kept only for a setup without the filter.

Position Anchor

What a physical token's millimetre position is measured against.

Owlbear only exposes the local viewport, so "this screen" means whichever machine this panel is open in. To anchor to the projector, run this panel on the projector client. Only ONE client should push positions -- two will fight over the same items.

Travel Mode

Pan or zoom the map without the minis "walking" across it. While travelling, token positions stop being pushed to the scene, so sliding the map under stationary minis cannot drag them through unexplored ground. Turn it off once the new area is in place.

Token Mapping

Persists with this scene -- no need to redo it next session.
